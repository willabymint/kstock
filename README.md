# K-Stock Screener (KOSPI/KOSDAQ 상위 300, 개인용·무료)

구조: **GitHub Actions(매일 수집·스코어링) → `docs/data/latest.json` → 정적 웹페이지(`docs/index.html`)**
서버/DB 비용 없음. 웹에서 가중치 슬라이더로 점수를 즉시 재계산합니다.

## 설치 (10분)
1. 이 폴더를 GitHub 저장소로 올립니다.
2. 무료 API 키 발급
   - **DART_API_KEY** (필수): https://opendart.fss.or.kr
   - **DATA_GO_KR_KEY** (수출, 권장): data.go.kr → "관세청_품목별 수출입실적(GW)"과 "관세청_품목별 국가별 수출입실적(GW)" 둘 다 활용신청 → 일반 인증키(Decoding)
   - KRX_ID / KRX_PW (선택): 연기금 순매수(pykrx). 안 되면 자동 생략
3. 저장소 Settings → Secrets → Actions 에 위 키 등록
4. Actions 탭에서 `check-connections` 실행 → 로그의 [OK]/[FAIL] 확인
5. Actions 탭에서 `daily-screen` 수동 실행(Run workflow) → 이후 평일 18:40 KST 자동 실행
6. Settings → Pages → Branch `main` / Folder `/docs`
   - 무료 플랜의 GitHub Pages는 **공개 저장소**만 가능합니다. 비공개로 쓰려면 Cloudflare Pages(무료)에 `docs/` 를 연결하세요.

**실데이터 연결 점검(먼저 한 번 실행 권장):** `DART_API_KEY=... DATA_GO_KR_KEY=... python -m pipeline.check`
→ 네이버/DART/관세청/pykrx가 각각 실제로 응답·파싱되는지 `[OK]/[FAIL]`로 보여줍니다. FAIL 항목이 있으면 그 줄의 메시지를 알려주세요.
`docs/data/latest.json`에 들어 있는 건 가짜 샘플이며, `python -m pipeline.run`(또는 Actions)을 실행하면 실제 데이터로 덮어씁니다. 가짜 데이터는 `tools/make_sample.py`를 직접 실행할 때만 만들어집니다.

로컬 실행: `pip install -r requirements.txt && DART_API_KEY=... python -m pipeline.run` 후 `cd docs && python -m http.server`
UI 미리보기(가짜 데이터): `python tools/make_sample.py`

## 화면 기능
- 종합 랭킹: 점수, 직전 실행 대비 변화, 연속 통과 횟수, NEW(신규 통과) 표시, 가중치 슬라이더, CSV 저장
- 종목 클릭: 핵심 근거, 플래그, 최근 주요 공시(DART 원문 링크), 섹터 수출 증가율, 세부 지표
- 저PBR·저배당·고지분 모음 탭
- 실행 이력은 `docs/data/history.json`에 최근 60회분 보관

## 판단 기준
**① 탈락(하드 필터)** — `pipeline/config.py` 의 `HARD`
매출 YoY < 5% / 영업이익 적자 / 영업현금흐름 마이너스 / 부채비율 > 200% / 자본잠식 / 당기순손실 / PER 적자·60 초과 / 일 거래대금 5억 미만 / 감사의견·관리종목·횡령배임·상장폐지 공시. 금융업은 순이익 증가 기준으로 대체.

**② 점수(9개 팩터, 가중치 조정 가능)**
| 팩터 | 내용 | 출처 |
|---|---|---|
| 수출 | 섹터 수출 3M/6M YoY·가속 + 영업이익 증가로 연결되는지 | 관세청 |
| 실적 | 매출·영업이익·순이익 YoY(최신 분기 누적 우선), 영업이익률 변화, 성장 가속 | DART |
| 재무 | 부채비율, 유동비율, 이익 대비 영업현금흐름, 이자보상 | DART |
| 밸류 | PER, PBR, 업종 중앙값 대비, 이익성장 대비 PER | 네이버 |
| 수급 | 외국인/기관 20일 순매수(시총 대비), 보유율 변화, 매수 일관성, 동반 순매수 | 네이버 |
| 연기금·패시브 | 국민연금 5%+ 지분과 증감, 연기금 순매수, 해외 장기투자자 5%+ 보유, 패시브 이벤트 | DART·KRX·수동CSV |
| 외국인관심 | 기업 IR 공시(원문에 해외/NDR 포함 여부), 국내 리포트 증가, 수동 기록 | DART·네이버·수동CSV |
| 지배구조 | 경영권 분쟁·공개매수·경영참여 보유(+), 자사주 소각·배당(+), 상속/최대주주 변동·저PBR저배당 오너(−), 증자/CB(−) | DART |
| 추세 | 60일 수익률(과열 감점), 고점 대비 위치 | 네이버 |

**③ 요청하신 것 외에 추가한 기준**: 영업현금흐름(이익의 질), 일회성 이익 의심(순이익≫영업이익), 이자보상배율, 업종 상대 밸류, 희석(유증/CB/BW), 리스크 공시, 유동성, 과열, 이익 성장 대비 PER, 주주환원(자사주 소각·배당성향), 데이터 커버리지 표시.

## 저PBR·저배당·고지분 별도 목록
웹의 두 번째 탭. 조건(`config.VALUE_WATCH`): PBR ≤ 0.5, 배당성향 < 20%, 최대주주+특수관계인 지분 ≥ 40%. 적자·자본잠식·리스크 공시·거래부족은 제외하고, 메인 랭킹의 성장 조건은 적용하지 않습니다.
싸다는 이유만으로 오르지는 않으므로 촉매(경영권 이슈, 자사주 소각, 밸류업 공시, 배당 증액, 외국인·기관 수급, 국민연금·해외 장기투자자 보유, 영업이익 증가, 패시브/IR)가 몇 개 겹치는지로 정렬하고, 상속 이력·희석·유통물량 부족 등 리스크를 옆에 표시합니다.

## 한계 (꼭 읽어주세요)
- **외국인 대상 영문 리포트/NDR 대상 종목은 무료 공개 소스가 없습니다.** 대신 기업 IR 공시 원문의 해외 키워드 + 국내 리포트 건수로 근사하고, 직접 확인한 종목은 `data/foreign_coverage.csv` 에 적으세요.
- **패시브 자금**(MSCI/KOSPI200 편입 등)도 자동 목록이 없어 `data/passive_events.csv` 수동 입력입니다.
- **연기금 순매수**는 KRX 접근(pykrx)에 의존해 막히면 빠지고, 이 경우 국민연금 5% 대량보유 공시만 사용됩니다. (5% 미만 보유 변동은 공시로 알 수 없음)
- **"상속으로 인한 주가 누르기"**는 공시 기반 휴리스틱(상속·증여 보고사유, 최대주주 변경, 저PBR·저배당·고지분)이며 확정 판정이 아닙니다.
- 관세청 API 응답 형식과 네이버 금융 HTML은 바뀔 수 있습니다. 첫 실행 후 화면 상단의 경고(⚠)와 Actions 로그를 확인하세요. 수출은 `data/export_manual.csv` 로 대체 가능합니다.
- 정량 필터는 후보를 좁히는 용도이며 투자 판단은 본인 책임입니다.
